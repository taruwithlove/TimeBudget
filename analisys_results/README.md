# Результаты анализа данных

В данной папке представлены результаты анализа данных проекта TimeBudget.

В ходе анализа были построены графики:
- Распределение времени по категориям.
- Распределение задач по статусам.
- Количество задач по приоритетам.
- Сравнение планируемого и фактического времени.
- Изменение затрат времени по дням.
- Распределение показателей продуктивности.

Также представлен файл summary.txt с основными статистическими показателями.
